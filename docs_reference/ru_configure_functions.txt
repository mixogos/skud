

# Использование функций FindFace Multi

FindFace Multi предлагает множество функций для использования. Некоторые из них доступны «из коробки», в то время как другие требуют настройки.

В этом разделе:

## Функции главного меню

Доступ к базовым функциям FindFace Multi осуществляется через веб-интерфейс. В главном меню может отображаться разное количество элементов в зависимости от наличия или отсутствия функциональности в вашей лицензии. Также, для некоторых функций требуется предварительное включение в файле конфигурации, после чего элемент появится в списке главного меню.

[img:navigation_menu_ru]

В этом разделе вы найдете информацию о том, требуется ли дополнительная настройка или приобретение лицензии для той или иной функциональности. Для большинства функций в документации есть подробное описание. Перейдите по ссылке в соответствующий раздел, чтобы узнать, как включить функциональность, если это требуется, и как с ней работать.

Примечание

Большинству функций FindFace Multi для работы требуются ресурсы, а именно: камеры, экземпляры extraction API, объекты TNT API. Ресурсы лицензируются отдельно и не рассматриваются в данной инструкции. Чтобы определить какие ресурсы включены в вашу лицензию, перейдите Лицензии → Основное.

[img:license_resources_ru]

Если вы предпочитаете работать с консолью, выполните следующую команду, чтобы увидеть какие ресурсы включены в вашу лицензию:

curl http://localhost:3185/v1/licenses.json -s | jq

Важно

Для работы с той или иной функциональностью пользователь должен обладать соответствующими правами. Подробнее о правах доступа роли пользователя в разделе Управление ролями и пользователями.

Картотека: доступно «из коробки», не настраивается, включено в лицензию по умолчанию (отдельно не лицензируется). Отключить данную функциональность невозможно.

Счётчики: доступно «из коробки», настраивается, включено в лицензию по умолчанию (отдельно не лицензируется). Отключить данную функциональность невозможно. Для конфигурации параметров счётчика, обратитесь к разделу Настройка счётчиков.

Видеостена: доступно «из коробки», настраивается, включено в лицензию по умолчанию (отдельно не лицензируется). На видеостене отображение атрибутов объекта в bbox зависит от включенных детекторов и атрибутов. Вы можете включить или отключить распознавание объектов и атрибутов, следуя этим инструкциям: Распознавание лиц и их атрибутов, Распознавание силуэтов и их атрибутов, Распознавание транспортных средств и их атрибутов.

Кластеры: по умолчанию отключено, настраивается, включено в лицензию по умолчанию (отдельно не лицензируется). FindFace Multi поддерживает автоматическую кластеризацию объектов одного происхождения: изображения лиц/силуэтов, принадлежащих одному человеку, изображения одного и того же транспортного средства. Возможны следующие алгоритмы кластеризации: кластеризация в реальном времени и кластеризация по расписанию. Узнайте, как включить кластеризацию для объекта или настроить определенный алгоритм кластеризации. Для кластеризации важно, чтобы сервис эпизодов был включен в конфигурационном файле findface-multi-legacy.py.

sudo vi /opt/findface-multi/configs/findface-multi-legacy/findface-multi-legacy.py

SERVICES = {
    "ffsecurity": {
        "episodes": True,
        ...
    }
}

Анализ взаимодействий: по умолчанию отключено, настройка возможна, включено в лицензию по умолчанию (отдельно не лицензируется). Чтобы начать использовать данную функциональность, включите кластеризацию лиц и кластеризацию в реальном времени.

Менеджер тревог, Журнал тревог, Тревожный монитор, каналы доставки: требуется покупка лицензии. Данная функциональность станет доступной после активации функционального модуля Тревоги в вашей лицензии. Чтобы использовать Telegram-бот в качестве канала доставки, вам следует сначала настроить его.

Карты: требуется покупка лицензии. Данная функциональность станет доступной после активации функционального модуля Карты в вашей лицензии. Возможна настройка параметров.

Аналитика BI: требуется установка и покупка лицензии. Данная функциональность станет доступной после активации функционального модуля BI аналитика в вашей лицензии. Аналитический сервис и BI-система Superset устанавливаются вместе с FindFace Multi из одного дистрибутива. Выберите соответствующие пункты во время инсталляции.

В: Do you want to install Analytics service?(y/n) (Хотите ли вы установить сервис аналитики?)

О: Отвечая да, вы установите сервис, который будет обрабатывать данные FindFace Multi для дальнейшего их использования в аналитических целях. На данный момент аналитика работает только для пересечения линий.

Do you want to install Analytics service?(y/n)
enable_analytics> y

В: Do you want to install Superset BI?(y/n) (Хотите ли вы установить BI-систему Superset?)

О: Установка внешней BI-системы позволяет вам просматривать данные FindFace Multi для пересечения линий в этой системе в виде графиков. FindFace Multi выступает в качестве источника данных, а внешняя BI-система помогает визуализировать данные. Отвечая y на этот вопрос, вы выбираете установку программного приложения с открытым исходным кодом Apache Superset . Если вы предпочитаете использовать собственную BI-систему, вы можете пропустить предложенную установку и ответить n.

Do you want to install Superset BI?(y/n)
install_superset> y

Пересечение линий: требуется приобретение лицензии. Данная функциональность станет доступной после активации функционального модуля Пересечение линий в рамках вашей лицензии.

Поиск: доступно «из коробки», не настраивается, включено в лицензию по умолчанию (отдельно не лицензируется).

## Другие функции

Внешние детекторы: доступно «из коробки», не настраивается, включено в лицензию по умолчанию (отдельно не лицензируется). Отключить данную функциональность невозможно.

Обработка загруженного видео: доступно «из коробки», включено в лицензию по умолчанию (отдельно не лицензируется). Для пользователя, который хочет использовать эту функциональность, должны быть включены соответствующие права доступа для сущности видеоархив.

Внешние системы управления видео (VMS): по умолчанию отключено, настраивается, требуется приобретение лицензии. Чтобы использовать данную функциональность, необходимо активировать функциональный модуль Внешние VMS в вашей лицензии и запросить плагин интеграции с VMS у представителя NtechLab. После этого настройте плагин, используя эту инструкцию.

PACS: отдельный сервис, который используется для партнерских интеграций. Приобретение лицензии не требуется. Для получения установочного файла и настройки сервиса обратитесь к представителю NtechLab.

Liveness: требуется установка, настраивается, требуется приобретение лицензии. Данная функциональность станет доступной после активации атрибута Liveness в вашей лицензии. Обнаружение витальности лиц может быть автоматически включено и настроено во время инсталляции.

В: Enable liveness and attempt to continue installation?(y/n) (Включить детектор витальности лиц liveness и продолжить установку?)

О: Данный вопрос появляется после запроса на установку и настройку функций обнаружения объектов и распознавания атрибутов объектов. Чтобы установить встроенный детектор витальности лиц, введите y. В противном случае введите n.

Enable liveness and attempt to continue installation?(y/n)
enable_liveness> y

Если вы ответили n на этом шаге, вы можете вручную включить определение витальности лиц позже, следуя инструкции в разделе Включение определения витальности лиц.

После установки (или ручной настройки) определения витальности лиц необходимо включить liveness в параметрах обработки видео камеры.

[img:liveness_setting_ru]

Атрибуты объектов: требуется установка, настройка возможна, требуется приобретение лицензии. Для работы распознавания атрибутов объекта необходимо активировать нужный атрибут в вашей лицензии. Атрибуты объекта лицензируются внутри ядра FindFace Multi, а именно в FindFace Server. Выполните следующую команду, чтобы получить полный список атрибутов, доступных для лицензирования:

curl http://localhost:3185/v1/licenses.json -s | jq

"products": {
  ...
  "server": {
    ...
    "features": {
      "body_bags": {
        "value": true
      },
      ...
      ...
    },

Детекторы и атрибуты могут быть автоматически настроены во время установки FindFace Multi. Инсталлятор задаст вам несколько вопросов (см. инструкцию по установке, вопросы 4.9-4.12). Или вы можете вручную включить распознавание объектов и их атрибутов: Распознавание лиц и их атрибутов, Распознавание силуэтов и их атрибутов, Распознавание транспортных средств и их атрибутов.

Видеомагнитофон: требуется установка, настраивается, требуется приобретение лицензии. Чтобы использовать эту функциональность, необходимо активировать функциональный модуль Видеозапись в рамках вашей лицензии. Чтобы установить Видеомагнитофон, ответьте y во время установки:

Do you want to install Video Recorder?(y/n)
install_video_recorder> y

Для настройки обратитесь к разделу Настройка Видеомагнитофона. Когда Видеомагнитофон развернут и настроен, в основных настройках камеры появится флажок Записывать видео. Включите запись видео в настройках камеры.

[img:record_video_ru]

Эпизоды и события:

Эпизоды: доступно «из коробки», настраивается, включено в лицензию по умолчанию (отдельно не лицензируется). Чтобы отключить эту функциональность, установите "episodes": False в секции SERVICES конфигурационного файла findface-multi-legacy.py.

sudo vi /opt/findface-multi/configs/findface-multi-legacy/findface-multi-legacy.py

SERVICES = {
    "ffsecurity": {
        "episodes": False,
        ...
    }
}

Параметры эпизодов можно настраивать. Роль пользователя должна иметь соответствующие права для получения уведомления о новом эпизоде.

События: доступно «из коробки», включено в лицензию по умолчанию (отдельно не лицензируется). Необходимые права доступа для роли (в зависимости от объекта): faceevent, bodyevent, carevent.
