# Сборка СКУД как настольного приложения

Приложение запускается в своём окне (без браузера и консоли) и ставится установщиком `seture.exe`.
Внутри работает сервер FastAPI, окно рисуется движком WebView2 (входит в Windows 11).

## Что где лежит

- `backend/desktop.py` — запуск приложения в окне (точка входа).
- `packaging/skud.spec` — сборка в автономное приложение (PyInstaller).
- `packaging/installer.iss` — установщик `seture.exe` (Inno Setup).
- `packaging/build.ps1` — собирает всё по порядку: интерфейс → приложение → установщик.
- `packaging/skud.ico` — значок приложения.

## Быстрая сборка (одной командой)

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

Результат:
- `dist\SKUD\SKUD.exe` — готовое приложение (папку `SKUD` можно переносить целиком).
- `dist\seture.exe` — установщик (если установлен Inno Setup).

## Сборка по шагам

1. Веб-интерфейс:
   ```powershell
   cd frontend; npm install; npm run build; cd ..
   ```
2. Приложение:
   ```powershell
   backend\.venv\Scripts\python -m PyInstaller --noconfirm --clean packaging\skud.spec
   ```
   → `dist\SKUD\SKUD.exe`
3. Установщик (нужен Inno Setup):
   ```powershell
   winget install JRSoftware.InnoSetup
   & "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" packaging\installer.iss
   ```
   → `dist\seture.exe`

## Как это работает у пользователя

- `seture.exe` ставит программу в папку пользователя (без прав администратора), создаёт значки в меню «Пуск» и на рабочем столе.
- Данные (база, загруженные фото и видео) хранятся в `%LOCALAPPDATA%\SKUD\data` — отдельно от самой программы, поэтому обновление приложения их не затирает.
- Модели распознавания и веб-интерфейс вшиты в приложение — интернет для работы не нужен.
- Приложение открывается сразу, без окна входа: доступ разрешён только с этого компьютера. Чтобы включить вход по логину и паролю, задайте переменную окружения `SKUD_NO_AUTH=0`.

## Примечания

- Первая загрузка моделей при первом распознавании занимает несколько секунд — это нормально.
- Размер приложения — порядка 400–500 МБ в основном из-за моделей нейросетей (≈200 МБ) и библиотек.
